# CHO R1 第1巻 P057 文字ネーム照合票（v2原本準拠）

## P057 — 外へ出る紙

1. 提出操作。白崎が『資料提出』を押す。宛先の固有名は見せない。白崎「送りました。」
2. 画面アップ。『添付資料：あり』『閲覧範囲：限定』。台詞なし。
3. 廊下。零が研究室を出る。右手で戸を開ける。台詞なし。
4. 御影と白崎。提出控えを見ている。白崎「この先、読む人は数字ばかり見ませんか。」

接続：P056で御影が零を名前で呼び記録への謝意を伝えた後、P057では添付と限定範囲を維持して資料を提出し、零は健康な右手で扉を開けて退出する。P058では御影が渡せる情報の範囲を整理し、外からの照会へつなぐ。宛先の固有名や新しいA1倫理前提は補作しない。
